# 🚀 CONTENTPULSE - INSTANT QUICK START

## ⚠️ YOUR PROJECT ISN'T RUNNING BECAUSE:
**MongoDB is NOT running or .env files are missing**

---

## ✅ FIX IN 5 MINUTES

### Step 1: Start MongoDB (Required!)
```bash
mongod
```
Wait for: `waiting for connections on port 27017`

### Step 2: Create These Files

**File: `backend/.env`**
```
NODE_ENV=development
PORT=3001
MONGODB_URI=mongodb://localhost:27017/contentpulse
LOG_LEVEL=info
FRONTEND_URL=http://localhost:3000
```

**File: `frontend/.env`**
```
VITE_API_URL=http://localhost:3001/api
VITE_WS_URL=ws://localhost:3001
```

### Step 3: Install & Run

```bash
npm install
```

Then **DOUBLE-CLICK:** `start-dev.bat`

### Step 4: Open Browser

```
http://localhost:5173
```

## 🆘 COMMON ISSUES

| Issue | Fix |
|-------|-----|
| "Cannot connect to MongoDB" | Run `mongod` in a terminal |
| "Port 3001 already in use" | Kill it: `taskkill /PID <number> /F` |
| ".env file not found" | Create the files in backend/ and frontend/ folders |
| Blank page on localhost:5173 | Check browser console (F12) for errors |
| "Module not found" | Run: `npm install` again |
