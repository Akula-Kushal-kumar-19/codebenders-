                      3. HOW TO OPEN THE WEBSITE
═══════════════════════════════════════════════════════════════════════════════

STEP 1: INSTALL MONGODB
────────────────────────────────────────────────────────────────────────────
Visit: https://www.mongodb.com/try/download/community
Download the Windows Community Edition installer
Install it (default options are fine)

STEP 2: START MONGODB
────────────────────────────────────────────────────────────────────────────
Open Command Prompt and run:
  $ mongod

Expected Output:
  mongod 7.0.0
  [initandlisten] waiting for connections on port 27017

✅ KEEP THIS TERMINAL OPEN


STEP 3: CREATE ENVIRONMENT FILES
────────────────────────────────────────────────────────────────────────────

File: backend/.env
Location: ContentPulse/backend/.env
Content:
───────────────────────────────────────────────────────────────────────────
NODE_ENV=development
PORT=3001
MONGODB_URI=mongodb://localhost:27017/contentpulse
LOG_LEVEL=info
FRONTEND_URL=http://localhost:3000
───────────────────────────────────────────────────────────────────────────

File: frontend/.env
Location: ContentPulse/frontend/.env
Content:
───────────────────────────────────────────────────────────────────────────
VITE_API_URL=http://localhost:3001/api
VITE_WS_URL=ws://localhost:3001
───────────────────────────────────────────────────────────────────────────


STEP 4: INSTALL DEPENDENCIES
────────────────────────────────────────────────────────────────────────────
Open Command Prompt in project root:
  $ npm install

Wait for completion (1-2 minutes)


STEP 5: START BACKEND SERVER
────────────────────────────────────────────────────────────────────────────
Open Command Prompt and run:
  $ cd backend
  $ npm run dev

Expected Output:
  > ts-node src/index.ts
  [info] ContentPulse server running on port 3001
  [info] Connected to MongoDB
  [info] WebSocket server running on port 3001

✅ KEEP THIS TERMINAL OPEN


STEP 6: START FRONTEND SERVER
────────────────────────────────────────────────────────────────────────────
Open Command Prompt and run:
  $ cd frontend
  $ npm run dev

Expected Output:
  VITE v4.5.14  ready in 363 ms
  ➜  Local:   http://localhost:5173/

✅ KEEP THIS TERMINAL OPEN


STEP 7: OPEN BROWSER
────────────────────────────────────────────────────────────────────────────
1. Open your web browser (Chrome, Firefox, Edge, etc.)
2. Go to: http://localhost:5173
3. Press Enter

🎉 YOU WILL SEE THE CONTENTPULSE DASHBOARD!
