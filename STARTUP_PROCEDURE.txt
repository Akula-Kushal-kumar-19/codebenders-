PART 2: MONGODB SETUP (REQUIRED!)
═══════════════════════════════════════════════════════════════════════════════

Option A: Local MongoDB (Recommended for Development)
─────────────────────────────────────────────────────

1. Download MongoDB Community Edition:
   URL: https://www.mongodb.com/try/download/community
   Select: Windows
   Download the .msi installer

2. Install MongoDB:
   • Run the downloaded installer
   • Follow the setup wizard
   • Default installation path: C:\Program Files\MongoDB\Server\7.0

3. Start MongoDB:
   • Open Command Prompt
   • Run: mongod
   • Expected output: "waiting for connections on port 27017"
   • ⚠️  KEEP THIS TERMINAL OPEN while testing


Option B: MongoDB Atlas (Cloud - No Installation)
──────────────────────────────────────────────────

1. Go to: https://www.mongodb.com/cloud/atlas
2. Create free account
3. Create a free cluster
4. Get connection string
5. Update backend/.env with the connection string


⚠️  IMPORTANT: MongoDB MUST be running before starting servers!

PART 9: TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Issue: "Cannot connect to MongoDB"
──────────────────────────────────────────────────────────────────────────
Solution:
  1. Make sure MongoDB terminal shows "waiting for connections on port 27017"
  2. Check backend/.env has correct MONGODB_URI
  3. If using Atlas, verify connection string and whitelist IP


Issue: "Port 3001 already in use"
──────────────────────────────────────────────────────────────────────────
Solution:
  1. Open Command Prompt
  2. Run: netstat -ano | findstr :3001
  3. Find the PID number
  4. Run: taskkill /PID <number> /F
  5. Try starting backend again


Issue: "Port 5173 already in use"
──────────────────────────────────────────────────────────────────────────
Solution:
  1. Open Command Prompt
  2. Run: netstat -ano | findstr :5173
  3. Find the PID number
  4. Run: taskkill /PID <number> /F
  5. Try starting frontend again


Issue: "Blank page in browser"
──────────────────────────────────────────────────────────────────────────
Solution:
  1. Press F12 to open Developer Console
  2. Check Console tab for error messages
  3. Check Network tab to see if API calls are working
  4. Verify backend is running on port 3001
  5. Verify frontend is running on port 5173


Issue: ".env file not found"
──────────────────────────────────────────────────────────────────────────
Solution:
  1. Create backend/.env in backend folder
  2. Create frontend/.env in frontend folder
  3. Add the required environment variables
  4. Restart servers


Issue: "npm: command not found"
──────────────────────────────────────────────────────────────────────────
Solution:
  1. Download Node.js: https://nodejs.org/
  2. Install it (includes npm)
  3. Restart Command Prompt
  4. Verify: npm --version
