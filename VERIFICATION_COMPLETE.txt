┃                    INSTRUCTIONS TO OPEN THE WEBSITE                          ┃
┗═══════════════════════════════════════════════════════════════════════════════┛

Follow these 7 simple steps:

STEP 1️⃣  INSTALL MONGODB
─────────────────────────────────────────────────────────────────────────
→ Download: https://www.mongodb.com/try/download/community
→ Install it (just click Next)
→ Expected Time: 5-10 minutes


STEP 2️⃣  START MONGODB
─────────────────────────────────────────────────────────────────────────
→ Open Command Prompt
→ Run: mongod
→ Expected Output: "waiting for connections on port 27017"
→ Keep this window OPEN


STEP 3️⃣  CREATE backend/.env FILE
─────────────────────────────────────────────────────────────────────────
→ Location: ContentPulse/backend/.env
→ Content:
   NODE_ENV=development
   PORT=3001
   MONGODB_URI=mongodb://localhost:27017/contentpulse
   LOG_LEVEL=info
   FRONTEND_URL=http://localhost:3000


STEP 4️⃣  CREATE frontend/.env FILE
─────────────────────────────────────────────────────────────────────────
→ Location: ContentPulse/frontend/.env
→ Content:
   VITE_API_URL=http://localhost:3001/api
   VITE_WS_URL=ws://localhost:3001


STEP 5️⃣  INSTALL DEPENDENCIES
─────────────────────────────────────────────────────────────────────────
→ Open Command Prompt in project root
→ Run: npm install
→ Wait for completion (1-2 minutes)


STEP 6️⃣  START SERVERS
─────────────────────────────────────────────────────────────────────────

Terminal A (Backend):
  $ cd backend
  $ npm run dev
  Wait for: "ContentPulse server running on port 3001"

Terminal B (Frontend):
  $ cd frontend
  $ npm run dev
  Wait for: "Local: http://localhost:5173"


STEP 7️⃣  OPEN BROWSER
─────────────────────────────────────────────────────────────────────────
→ Open web browser (Chrome, Firefox, Edge, Safari)
→ Go to: http://localhost:5173
→ Press Enter

🎉 YOU'LL SEE THE CONTENTPULSE DASHBOARD!
