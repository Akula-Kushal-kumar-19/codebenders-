PREREQUISITES SETUP:
┌────────────────────────────────────────────────────────────────────────┐
│                                                                        │
│ 1. MONGODB INSTALLATION & RUNNING                                     │
│    ────────────────────────────────────────────────────────           │
│    Download: https://www.mongodb.com/try/download/community          │
│    Install it (just click Next)                                       │
│                                                                        │
│    Then open Command Prompt and run:                                  │
│    $ mongod                                                           │
│                                                                        │
│    Wait for: "waiting for connections on port 27017"                 │
│    ✅ KEEP THIS TERMINAL OPEN                                        │
│                                                                        │
│ 2. CREATE backend/.env                                                │
│    ────────────────────────────────────────────────────────           │
│    Location: ContentPulse/backend/.env                                │
│    Content:                                                           │
│      NODE_ENV=development                                            │
│      PORT=3001                                                        │
│      MONGODB_URI=mongodb://localhost:27017/contentpulse              │
│      LOG_LEVEL=info                                                  │
│      FRONTEND_URL=http://localhost:3000                              │
│                                                                        │
│ 3. CREATE frontend/.env                                               │
│    ────────────────────────────────────────────────────────           │
│    Location: ContentPulse/frontend/.env                               │
│    Content:                                                           │
│      VITE_API_URL=http://localhost:3001/api                          │
│      VITE_WS_URL=ws://localhost:3001                                 │
│                                                                        │
└────────────────────────────────────────────────────────────────────────┘

Issue: Cannot connect to MongoDB
Fix:   Make sure mongod terminal shows "waiting for connections on port 27017"

Issue: Port 3001 already in use
Fix:   netstat -ano | findstr :3001
       taskkill /PID <number> /F

Issue: Port 5173 already in use
Fix:   netstat -ano | findstr :5173
       taskkill /PID <number> /F

Issue: Blank page or errors in browser
Fix:   Press F12 → Check Console tab for error messages

Issue: Cannot find module
Fix:   npm install

Issue: .env files not found
Fix:   Create backend/.env and frontend/.env in their respective folders
