┌────────────────────────────────────────────────────────────────────┐
│ STEP 1: INSTALL & START MONGODB (THE DATABASE)                   │
└────────────────────────────────────────────────────────────────────┘

  ✓ Download: https://www.mongodb.com/try/download/community
  ✓ Install (just click Next)
  ✓ Open Command Prompt
  ✓ Run: mongod
  ✓ Wait for: "waiting for connections on port 27017"
  ✓ KEEP THIS WINDOW OPEN

  💡 Takes 3-5 minutes if you need to download


┌────────────────────────────────────────────────────────────────────┐
│ STEP 2: CREATE backend/.env FILE                                  │
└────────────────────────────────────────────────────────────────────┘

  Location: ContentPulse/backend/.env
  
  Content:
  ─────────────────────────────────────────────────────
  NODE_ENV=development
  PORT=3001
  MONGODB_URI=mongodb://localhost:27017/contentpulse
  LOG_LEVEL=info
  FRONTEND_URL=http://localhost:3000
  ─────────────────────────────────────────────────────

  📝 Just copy-paste the above into the file


┌────────────────────────────────────────────────────────────────────┐
│ STEP 3: CREATE frontend/.env FILE                                 │
└────────────────────────────────────────────────────────────────────┘

  Location: ContentPulse/frontend/.env
  
  Content:
  ─────────────────────────────────────────────────────
  VITE_API_URL=http://localhost:3001/api
  VITE_WS_URL=ws://localhost:3001
  ─────────────────────────────────────────────────────

  📝 Just copy-paste the above into the file


┌────────────────────────────────────────────────────────────────────┐
│ STEP 4: INSTALL DEPENDENCIES                                      │
└────────────────────────────────────────────────────────────────────┘

  ✓ Open Command Prompt in project root
  ✓ Run: npm install
  ✓ Wait for completion (1-2 minutes)

  💡 This downloads all required packages


┌────────────────────────────────────────────────────────────────────┐
│ STEP 5: START THE SERVERS                                         │
└────────────────────────────────────────────────────────────────────┘

  EASIEST WAY:
  ✓ Find file: start-dev.bat
  ✓ Double-click it
  ✓ Two new terminals will open
  ✓ Wait for "ready" messages

  OR MANUAL WAY:
  Terminal A:  cd backend && npm run dev
  Terminal B:  cd frontend && npm run dev
